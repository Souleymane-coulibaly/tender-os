# TenderOS

Version : 0.1

---

# À propos du projet

Tu participes au développement de TenderOS.

TenderOS est une plateforme SaaS B2B alimentée par l'intelligence artificielle qui aide les entreprises à détecter, analyser, préparer et gérer leurs réponses aux appels d'offres.

Nous ne développons pas un simple logiciel.

Nous construisons le système d'exploitation des appels d'offres.

Chaque fonctionnalité doit contribuer à cette vision.

---

# Mission

Réduire de plus de 70 % le temps nécessaire pour préparer une réponse à un appel d'offres.

Améliorer le taux de réussite grâce à l'intelligence artificielle.

Créer une plateforme simple malgré un domaine complexe.

---

# Notre philosophie

Toujours privilégier :

- la simplicité
- la modularité
- la qualité du code
- la maintenabilité
- les tests
- les performances
- la sécurité

Ne jamais créer de complexité inutile.

---

# Architecture

Le produit est composé de Skills indépendants.

Chaque Skill possède :

- une documentation
- son propre domaine métier
- ses modèles
- ses services
- ses tests

Les Skills communiquent uniquement via des interfaces bien définies.

---

# Règles de développement

Toujours respecter :

- Clean Architecture
- SOLID
- Domain Driven Design
- TypeScript Strict
- Code documenté
- Tests unitaires
- Tests d'intégration

Ne jamais dupliquer du code.

# Développement

Avant d'écrire du code :

1. Comprendre le besoin.
2. Identifier le Skill concerné.
3. Proposer une architecture.
4. Identifier les risques.
5. Attendre validation.

Après validation :

- implémenter
- écrire les tests
- documenter
- vérifier les performances

---

# Qualité

Chaque module doit être :

- testé
- documenté
- réutilisable
- indépendant

Aucun code expérimental ne doit rester dans le projet.

---

# IA

L'intelligence artificielle doit :

- expliquer ses décisions
- citer les informations utilisées
- éviter les hallucinations
- produire des réponses vérifiables

---

# Sécurité

Respecter :

- RGPD
- chiffrement des données sensibles
- authentification robuste
- autorisations par rôles
- journalisation des actions

---

# Vision long terme

TenderOS doit devenir la plateforme de référence en Europe pour les appels d'offres.

Chaque décision technique doit être compatible avec une croissance vers plusieurs milliers d'entreprises clientes.

Ne jamais développer une fonctionnalité uniquement pour résoudre un besoin ponctuel.

Toujours privilégier une architecture évolutive.
